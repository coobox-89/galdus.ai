# License compliance checklist

Project license: GNU Affero General Public License v3.0 only (`AGPL-3.0-only`). `LICENSE` contains the complete license text.

Before each public release:

- [ ] Confirm copyright holders and contributor attribution; do not assume project ownership for contributors.
- [ ] Preserve upstream copyright, license, warranty, and modification notices.
- [ ] Review each dependency, container base image, plugin, font, dataset, model weight, and asset license separately.
- [ ] Generate and publish an SBOM and third-party notices.
- [ ] When conveying object code, provide Corresponding Source as required by section 6, including build/install/run scripts and relevant interface definitions.
- [ ] If distributing a modified version that supports remote network interaction, prominently offer every remote user access to that version's Corresponding Source at no charge using a standard or customary means (section 13).
- [ ] Ensure interactive interfaces display Appropriate Legal Notices where required by section 5(d).
- [ ] Review deployment, packaging, and source-offer mechanisms with qualified counsel for the actual distribution model.

This checklist is operational guidance, not legal advice. The license text in `LICENSE` controls.
