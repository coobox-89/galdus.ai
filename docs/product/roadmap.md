# Product roadmap

This is a directional roadmap, not a statement of completed features.

1. Foundation: API, web console, local development and provider-neutral model gateway.
2. Identity: accounts, organizations, RBAC and tenant boundaries.
3. Models: provider catalog, routing, quotas, budgets and usage telemetry.
4. Agents: definitions, tools, run history, scoped memory and approvals.
5. Knowledge: ingestion, indexing, retrieval, permissions and citations.
6. Automation: schedules, triggers, retries and human tasks.
7. MCP: managed server connections and scoped credentials.
8. Governance: audit, policy controls and operational visibility.
9. Deployment: self-hosted team and enterprise profiles.
